# RT24｜醫事放射師的一天

免安裝的 3D 模擬小遊戲。當一天醫事放射師：叫病人、X 光擺位、抓吸氣時機曝光、推行動式 X 光機跑急診、評估 CT 顯影劑風險、拉掃描範圍、做 MRI 安全篩檢，最後交班看看今天的表現。

**▶ 線上試玩：** （GitHub Pages 開啟後把網址貼在這裡）

## 怎麼玩

- 跟著頭上有「！」、地上有黃色光圈的人或機器走，或按「帶我去」
- 走動：方向鍵、WASD，或點地板
- 互動：走近按 E（或點畫面下方的按鈕）
- 右上角 🔊 / 🎵 分別開關音效與音樂；「圖鑑」可以看解鎖的名詞

手機和電腦瀏覽器都能玩。

## 在自己電腦上執行

這是純靜態網頁，在專案資料夾執行任一種靜態伺服器即可，例如：

```bash
python -m http.server 5173
```

然後打開 <http://localhost:5173>。3D 引擎 three.js 透過 CDN 載入，需要網路。

## 專案結構

| 檔案 | 內容 |
|---|---|
| `index.html`、`css/style.css` | 頁面與介面樣式 |
| `js/world.js` | 3D 場景、角色、NPC 行為與尋路 |
| `js/ui.js` | 對話、選擇面板與小遊戲 |
| `js/story.js` | 劇情、選項與圖鑑內容 |
| `js/audio.js` | 音效與背景音樂（WebAudio 即時合成） |
| `js/main.js` | 遊戲流程與結算 |
| `tools/gen_xray.py` | 產生遊戲中 X 光／CT 示意圖的程式 |

## 關於影像與內容

- 遊戲中的胸部 X 光與 CT 定位像，都是 `tools/gen_xray.py` 以程式合成的示意圖，不是真實病人影像。
- 音效與音樂皆為瀏覽器即時合成，沒有使用外部音檔。
- 病人、數值、流程與人物都是虛構並經過簡化的遊戲設定，不代表任何醫院的實際規範，也不是臨床指引。
